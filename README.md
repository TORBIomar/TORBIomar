- 🎓 **Engineering Student** in Computer and Network Engineering (**IIR**) at **EMSI Rabat**.

- 👥 Open to collaborations on **Full-Stack SaaS**, **3D Web Engineering (Three.js/Wasm)**, and **Cloud/AI Systems**.
