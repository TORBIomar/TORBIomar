## 🚀 Technical Focus Areas

- 📐 **3D WebCAD & Advanced Manufacturing** — Architecting in-browser parametric tube modeling kernels, dynamic 2D flat-pattern unrolling, deterministic cutting-path calculation, and manufacturing-ready CNC G-code generation. Leverage **Three.js**, **React Three Fiber**, and **OpenCascade.js WASM**.
- ⚙️ **Enterprise-Grade Backends** — Designing highly available, secure RESTful microservices, complex multi-tenant data pipelines, and robust authentication systems using **Java**, **Spring Boot**, and **Spring Security**.
- 🗄️ **Data Persistence & Cloud Infrastructure** — Modifying performant relational schemas for scale, implementing transactional integrity on **MySQL** / **Oracle DB**, and deploying automated CI/CD workflows on **Oracle Cloud Infrastructure (OCI)** and **Docker**.
- 🔍 **Vector Retrieval & AI Integration** — Implementing semantic search patterns and retrieval-augmented generation (RAG) using **ChromaDB** vector storage and the **Gemini API** for contextual document intelligence.
